### ✅ Добавлено отображение количества дней

В карточках статистики теперь показывается:
- **Общая выручка**: Количество дней в периоде + процент роста
- **Количество продаж**: Количество дней в периоде + процент роста

Пример:
```
ОБЩАЯ ВЫРУЧКА
43 659 197,62 AMD
 -34.8% к прошл. месяцу
📅 24 дней в месяце
```

### ✅ Улучшенная визуализация

- Иконки для каждого периода сравнения:
  - 📅 Прошлый месяц
  - 📆 Прошлый год
  - ⏰ 10 лет назад
  
- Цветовая индикация:
  - 🟢 Зеленый = рост (положительный %)
  - 🔴 Красный = падение (отрицательный %)

- Детализация значений:
  - Процент изменения (крупно)
  - Текущее значение
  - Прошлое значение

## Как это работает

### Вычисление дней в периоде

JavaScript функция `updateDaysCount()`:
```javascript
updateDaysCount() {
    if (this.dateFrom && this.dateTo) {
        const from = new Date(this.dateFrom);
        const to = new Date(this.dateTo);
        const diffTime = Math.abs(to - from);
        this.currentDaysInMonth = Math.ceil(diffTime / (1000 * 60 * 60 * 24)) + 1;
    } else {
        this.currentDaysInMonth = new Date().getDate();
    }
}
```

### Обновление при изменении фильтров

При изменении дат количество дней пересчитывается автоматически:
```javascript
applyFilters() {
    this.updateDaysCount();  // ← Пересчет дней
    this.loadStats();
    this.loadCharts();
    this.loadDebts();
    this.loadSummary();
}
```

## Пример использования

### Сценарий 1: Анализ текущего месяца до сегодняшнего дня

1. Выбран период: 01.11.2024 - 24.11.2024 (24 дня)
2. Сравнение с прошлым месяцем: 01.10.2024 - 24.10.2024 (те же 24 дня!)
3. Сравнение с прошлым годом: 01.11.2023 - 24.11.2023 (те же 24 дня!)

**Результат**: Честное сравнение "день в день"

### Сценарий 2: Анализ полного месяца

1. Выбран период: 01.10.2024 - 31.10.2024 (31 день)
2. Сравнение с прошлым месяцем: 01.09.2024 - 30.09.2024 (30 дней)
3. Сравнение корректируется по дням

**Результат**: Видно реальную динамику с учетом разного количества дней

## Преимущества

### 1. Честное сравнение
- Сравниваются одинаковые периоды (день в день)
- Учитывается, что в месяце может быть 28, 30 или 31 день
- Нет искажения из-за незавершенного месяца

### 2. Наглядность
- Сразу видно, за сколько дней получена статистика
- Понятно, почему идет падение (например, прошло только 10 дней, а не весь месяц)
- Четкое отображение текущих и прошлых значений

### 3. Контекст
- При анализе 10 ноября видим сравнение с 10 октября (не с 31 октября)
- Исключается эффект "недозагрузки" текущего месяца
- Реальная картина роста/падения продаж
