╔══════════════════════════════════════════════════════════════════════════════════════════════════════╗
║                                   СВЯЗИ (RELATIONSHIPS)                                               ║
╚══════════════════════════════════════════════════════════════════════════════════════════════════════╝

1️⃣  CUSTOMERS → SALES (ONE-TO-MANY)
   ────────────────────────────────
   • Один клиент может иметь много продаж
   • Каждая продажа принадлежит одному клиенту
   • FK: Sales.CustomerID → Customers.CustomerID
   • ON DELETE: NO ACTION (нельзя удалить клиента с продажами)


2️⃣  SALES → SALEDETAILS (ONE-TO-MANY)
   ───────────────────────────────────
   • Одна продажа может содержать много позиций
   • Каждая позиция принадлежит одной продаже
   • FK: SaleDetails.SaleID → Sales.SaleID
   • ON DELETE: CASCADE (при удалении продажи удаляются все позиции)


3️⃣  PRODUCTS → SALEDETAILS (ONE-TO-MANY)
   ────────────────────────────────────
   • Один продукт может быть в многих продажах
   • Каждая позиция ссылается на один продукт
   • FK: SaleDetails.ProductID → Products.ProductID
   • ON DELETE: NO ACTION (нельзя удалить продукт с историей продаж)

╔══════════════════════════════════════════════════════════════════════════════════════════════════════╗

📊 CUSTOMERS
   • PK_Customers (CLUSTERED) → CustomerID
   • IX_Customers_Name → CustomerName
   • IX_Customers_Location → Country, City
   • IX_Customers_Email → Email

📊 PRODUCTS
   • PK_Products (CLUSTERED) → ProductID
   • IX_Products_Name → ProductName
   • IX_Products_Category → Category
   • IX_Products_Stock → StockQuantity (WHERE > 0)

📊 SALES
   • PK_Sales (CLUSTERED) → SaleID
   • FK_Sales_Customers → CustomerID
   • IX_Sales_Date → SaleDate DESC
   • IX_Sales_Status → Status
   • IX_Sales_CustomerDate → CustomerID, SaleDate DESC

📊 SALEDETAILS
   • PK_SaleDetails (CLUSTERED) → SaleDetailID
   • FK_SaleDetails_Sales → SaleID
   • FK_SaleDetails_Products → ProductID
   • IX_SaleDetails_Composite → SaleID, ProductID INCLUDE (Quantity, Subtotal)

╔══════════════════════════════════════════════════════════════════════════════════════════════════════╗

🔧 TR_SaleDetails_UpdateSaleTotalAmount
   ────────────────────────────────────
   ТАБЛИЦА: SaleDetails
   СОБЫТИЕ: AFTER INSERT, UPDATE, DELETE
   ДЕЙСТВИЕ: Автоматически пересчитывает Sales.TotalAmount = SUM(SaleDetails.Subtotal)


🔧 TR_SaleDetails_CheckStock
   ──────────────────────────
   ТАБЛИЦА: SaleDetails
   СОБЫТИЕ: INSTEAD OF INSERT
   ДЕЙСТВИЕ: 
     1. Проверяет наличие товара (Products.StockQuantity >= Quantity)
     2. Если OK → вставляет данные + уменьшает StockQuantity
     3. Если НЕТ → ROLLBACK с ошибкой "Недостаточно товара"


🔧 TR_SaleDetails_RestoreStock
   ────────────────────────────
   ТАБЛИЦА: SaleDetails
   СОБЫТИЕ: AFTER DELETE
   ДЕЙСТВИЕ: Возвращает товар на склад (StockQuantity += Quantity)

📌 sp_CreateSale
   Создание новой продажи
   IN:  @CustomerID, @Notes
   OUT: @NewSaleID

📌 sp_AddSaleItem
   Добавление товара в продажу
   IN: @SaleID, @ProductID, @Quantity

📌 sp_CompleteSale
   Завершение продажи (Status='Completed')
   IN: @SaleID

📌 sp_CancelSale
   Отмена продажи с возвратом товара
   IN: @SaleID

📌 sp_SalesReport
   Отчет по продажам за период
   IN: @StartDate, @EndDate

📌 sp_TopSellingProducts
   Топ продаваемых товаров
   IN: @TopN, @StartDate, @EndDate

📌 sp_CustomerPurchaseHistory
   История покупок клиента
   IN: @CustomerID
