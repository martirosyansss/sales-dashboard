# 📅 Фильтры по датам и сравнение периодов

## ✅ Что добавлено (13.11.2025)

### 🎯 Основные возможности:

1. **Выбор периода анализа**
   - Date picker "От" - начало периода
   - Date picker "До" - конец периода
   - Кнопка сброса на текущий месяц

2. **Быстрый выбор периода**
   - ✅ Этот месяц
   - ✅ Прошлый месяц
   - ✅ Этот год

3. **Сравнение с предыдущими периодами**
   - ✅ К прошлому месяцу
   - ✅ К прошлому году (этот же месяц)
   - ✅ К 10 лет назад (этот же месяц)

---

## 📊 Метрики сравнения

### Для каждого периода показываются:

**Выручка:**
- Текущий период
- Процент роста к прошлому месяцу
- Процент роста к прошлому году (YoY)
- Процент роста к 10 лет назад
- Абсолютные значения всех периодов

**Количество продаж:**
- Текущий период
- Процент роста к прошлому месяцу
- Процент роста к прошлому году (YoY)
- Процент роста к 10 лет назад
- Абсолютные значения всех периодов

## 🔍 Логика расчетов

### Прошлый месяц:
```python
# Если выбран январь 2025
current: 2025-01-01 → 2025-01-31
prev:    2024-12-01 → 2024-12-31

growth = (current - prev) / prev * 100
```

### Прошлый год (YoY):
```python
# Если выбран январь 2025
current:   2025-01-01 → 2025-01-31
last_year: 2024-01-01 → 2024-01-31  # Тот же месяц!

growth_yoy = (current - last_year) / last_year * 100
```

### 10 лет назад:
```python
# Если выбран январь 2025
current:         2025-01-01 → 2025-01-31
ten_years_ago:   2015-01-01 → 2015-01-31  # Тот же месяц!

growth_10y = (current - ten_years_ago) / ten_years_ago * 100
```

## 🚀 Использование

### JavaScript (Alpine.js):

```javascript
// Установить текущий месяц
setThisMonth() {
    const today = new Date();
    const firstDay = new Date(today.getFullYear(), today.getMonth(), 1);
    const lastDay = new Date(today.getFullYear(), today.getMonth() + 1, 0);
    
    this.dateFrom = this.formatDate(firstDay);
    this.dateTo = this.formatDate(lastDay);
    this.loadStats();
}

// Загрузить данные с фильтрами
async loadStats() {
    let url = '/api/dashboard/stats';
    if (this.dateFrom && this.dateTo) {
        url += `?date_from=${this.dateFrom}&date_to=${this.dateTo}`;
    }
    
    const response = await fetch(url);
    const result = await response.json();
    this.stats = result.data;
}
```
