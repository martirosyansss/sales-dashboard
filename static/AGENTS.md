# static

## Назначение
Статические ресурсы Flask, отдаваемые по `/static/...`. В проекте фронтенд-JS в основном
инлайнится в шаблоны (см. `../templates/AGENTS.md`), поэтому здесь минимум файлов.

## Ключевые файлы
| Файл | Описание |
|------|----------|
| `css/style.css` | Общие пользовательские стили (поверх Bootstrap с CDN) |
| `favicon.ico` | Иконка вкладки; также отдаётся маршрутом `/favicon.ico` в app_v2.py |

## Подкаталоги
| Каталог | Назначение |
|---------|------------|
| `css/` | Пользовательские стили |
| `js/` | Зарезервирован под JS; обычно пуст — скрипты живут инлайн в шаблонах |

## Для AI-агентов

### Работа в этом каталоге
- Глобальные стили → `css/style.css`. Специфичный для страницы CSS чаще в самом шаблоне.
- Не добавляй сюда внешние библиотеки локально — они подключаются с CDN в шаблонах.

### Проверка
- Изменения стилей проверяй визуально в браузере (жёсткая перезагрузка/сброс кеша).

## Зависимости

### Внутренние
- `../templates/*` подключают `style.css` и иконку.
