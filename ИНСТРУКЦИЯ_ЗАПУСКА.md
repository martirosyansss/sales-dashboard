## 🚀 Быстрый старт

### Способ 1: Двойной клик (самый простой)
1. Найдите файл `start_web.bat`
2. Дважды кликните на нем
3. Откройте браузер по адресу: http://localhost:5000

### Способ 2: PowerShell
```powershell

cd "c:\Sales Dashboard"

# Установите зависимости (один раз)
python -m pip install Flask pyodbc

# Запустите приложение
python app.py
```

### Способ 3: Command Prompt
```cmd
cd "c:\Sales Dashboard"
python -m pip install Flask pyodbc
python app.py
```

## 📋 Что нужно перед запуском?

### ✅ Проверьте установку Python
Откройте PowerShell и выполните:
```powershell

```
Должна отобразиться версия Python (например: Python 3.11.0)

**Если Python не установлен:**
1. Скачайте с https://www.python.org/downloads/
2. При установке отметьте "Add Python to PATH"
3. Перезагрузите компьютер

### ✅ Проверьте SQL Server
- Убедитесь, что SQL Server запущен
- Сервер: localhost
- Логин: sa
- Пароль: Aa123456

**Проверка через PowerShell:**
```powershell
sqlcmd -S localhost -U sa -P Aa123456 -Q "SELECT @@VERSION"
```

## 🛠️ Устранение проблем

### Проблема: "Python was not found"
**Решение:**
1. Установите Python с python.org
2. Или используйте Microsoft Store: `python`
3. Перезагрузите компьютер

### Проблема: "Failed to connect to database"
**Решение:**
1. Запустите SQL Server
2. Проверьте логин/пароль (sa/Aa123456)
3. Включите TCP/IP в SQL Server Configuration Manager
4. Перезапустите службу SQL Server

### Проблема: "Port 5000 is already in use"
**Решение:**
1. Остановите другое приложение на порту 5000
2. Или измените порт в файле `app.py`:
```python
app.run(debug=True, host='0.0.0.0', port=5001)
```

### Проблема: "ModuleNotFoundError: No module named 'flask'"
**Решение:**
```powershell
python -m pip install Flask pyodbc --upgrade
```
