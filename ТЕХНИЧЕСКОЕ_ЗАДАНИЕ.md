## 👥 РОЛИ И ПОЛЬЗОВАТЕЛИ

### 1. **Менеджеры по продажам**
- **Роль:** Сотрудники компании, продающие товар клиентам B2B
- **Территория:** У каждого менеджера своя территория (регион/город)
- **Клиенты:** У каждого менеджера закреплены свои клиенты
- **Задачи:** Прямые продажи, работа с клиентами на местах

### 2. **Дистрибьюторы**
- **Роль:** Партнеры компании
- **Функция:** Продают товар компании в различных регионах и городах
- **Отношения:** Работают независимо от менеджеров
- **Задачи:** Оптовые закупки, региональная дистрибуция

### 3. **Сетевые магазины (Сети)**
- **Роль:** Крупные розничные сети (супермаркеты, торговые сети)
- **Структура:** Один клиент может быть частью сети
- **Отношения:** Работают с менеджерами (не связаны с дистрибьюторами)
- **Важность:** Требуется отдельная аналитика по прибыльности сетей

## 🎨 ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 1. 📊 DASHBOARD (Главная страница)

#### Статистические карточки (8 штук):
1. **Общая выручка** (текущий месяц + % к прошлому)
2. **Количество продаж** (текущий месяц + % к прошлому)
3. **Средний чек** (с трендом)
4. **Активные клиенты** (количество)
5. **Топ менеджер месяца** (ФИО + выручка)
6. **Топ дистрибьютор** (название + объем)
7. **Топ сеть** (название + прибыль)
8. **Остатки на складе** (количество товаров)

#### Графики (6 основных):
1. **Динамика продаж** (линейный график)
   - Период: день/неделя/месяц/год (переключатель)
   - Сравнение: текущий период vs прошлый период
   - Сравнение: текущий год vs прошлый год (YoY)

2. **Распределение по категориям** (круговая диаграмма)
   - Доля каждой категории товаров
   - % и сумма

3. **Топ-10 товаров** (горизонтальная диаграмма)
   - По количеству продаж
   - По выручке

4. **Рейтинг менеджеров** (вертикальная диаграмма)
   - ТОП-10 по выручке
   - С планом продаж (% выполнения)

5. **Динамика по дистрибьюторам** (линейный график)
   - Объемы поставок за период
   - Сравнение дистрибьюторов

6. **Карта продаж по регионам** (географическая карта)
   - Тепловая карта регионов
   - Выручка по городам

#### Дополнительные графики:
7. **Воронка продаж**
   - Этапы: лиды → переговоры → заказы → оплата
   - Конверсия на каждом этапе

8. **Прогноз продаж** (линейный график с прогнозом)
   - На основе исторических данных
   - Линейная регрессия или moving average
   - Прогноз на 1-3 месяца вперед

#### Элементы Dashboard:
- **Drag & Drop** - все элементы можно перетаскивать
- **Show/Hide** - кнопка "глаз" для скрытия виджетов
- **Resize** - изменение размера виджетов
- **Сохранение** - позиции сохраняются в localStorage
- **Сброс** - кнопка "Reset Layout" для возврата к дефолтному

```css
:root {
  --bg-primary: #ffffff;

  --text-secondary: #6c757d;
  --border-color: #dee2e6;
  --accent-color: #0d6efd;

```

#### Темная тема:
```css
[data-theme="dark"] {
  --bg-primary: #1a1a1a;
  --bg-secondary: #2d2d2d;
  --text-primary: #e0e0e0;
  --text-secondary: #a0a0a0;
  --border-color: #404040;
  --accent-color: #4a9eff;
}
```

### Переключатель:
```html
<button id="theme-toggle" class="btn">
  <i class="fas fa-moon"></i> <!-- или fa-sun -->
</button>
```

### JavaScript:
```javascript
const themeToggle = document.getElementById('theme-toggle');
themeToggle.addEventListener('click', () => {
  const currentTheme = document.documentElement.getAttribute('data-theme');
  const newTheme = currentTheme === 'dark' ? 'light' : 'dark';
  document.documentElement.setAttribute('data-theme', newTheme);
  localStorage.setItem('theme', newTheme);
});
```
