# Araqich: полный релиз 27.10.2026

Релиз сохраняет действующий код CT115 в истории `main`: пошаговую подготовку развоза, восстановление черновика и защиту несохранённых решений, обмен рейсов машин с проверками ограничений, выбор сегодняшней даты до 16:00 по Еревану и следующей календарной даты после, уточнения карты и веса доставок, экспорт шапок заказов в стандартный шаблон ArmSoft, отдельный журнал заправок.

Исходники восстановлены в отдельном checkout из `origin/main` и сверены с полным набором файлов работающего приложения. Исторический локальный checkout недоступен; коммит из старого серверного manifest отсутствует на GitHub. Этот релиз продолжает доступную историю `main` и включает все изменения текущего работающего приложения. Незавершённый эксперимент с использованием резерва грузоподъёмности сюда не включён.

В серверный пакет входят `app_v2.py`, `requirements.txt`, Python-модули `courier` и `route_optimizer`, `static` и `templates`, включая пустой стандартный `SalesOrder.xlsm`. Учётные данные, настройки пользователей, фотографии, APK, рабочие базы и данные карт остаются вне Git и пакета.

Проверки выполняются по [инструкции](../deploy/verification/README.md). При установке нужен согласованный резервный снимок обеих SQLite, проверка исходных хешей и переключение `/opt/araqich/app` на каталог полного релиза. Текущие зависимости не меняются; рабочие данные находятся в `/var/lib/araqich`, настройки среды — в `/etc/araqich/araqich.env`.
