# templates

## Назначение
Jinja2-шаблоны Flask для Sales Dashboard. Здесь же живёт **почти весь фронтенд-JavaScript**
(инлайн в `<script>`) — отдельной сборки нет, библиотеки подключаются с CDN. Наследуют базовый
шаблон и рендерятся маршрутами из [../app_v2.py](../app_v2.py). Есть параллельный набор v1/v2:
актуальны файлы v2 и крупные функциональные страницы.

## Для AI-агентов

### Работа в этом каталоге
- Правки UI v2 → соответствующий `*_v2.html` / крупная страница, наследующая `base_v2.html`.
- JS правится **внутри шаблона** (инлайн `<script>`), а не в `static/js`.
- Библиотеки — с CDN; не добавляй бандлеры/npm без запроса.
- Данные приходят из JSON-эндпоинтов `/api/...` через `fetch`/HTMX; сверяйся с сигнатурой
  соответствующего маршрута в `app_v2.py`.
- Весь пользовательский текст — на русском.

### Проверка
- Запусти `python app_v2.py`, открой нужный маршрут в браузере, проверь консоль на ошибки JS.
- Крупные файлы (`dashboard_builder`, `areas`, `plans`) тяжёлые — редактируй точечно (Edit),
  не переписывай целиком.

### Частые паттерны
- Chart.js для графиков, AG-Grid для таблиц клиентов, SortableJS для drag&drop, Alpine.js
  для реактивности, Bootstrap 5 для вёрстки, Font Awesome для иконок.
- Тёмная/светлая тема через классы/атрибуты в `base_v2.html`.

## Зависимости
