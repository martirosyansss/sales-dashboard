# Sales Management Web Application

## 🚀 Современное веб-приложение для управления продажами

Полнофункциональная веб-система с красивым интерфейсом, интерактивными графиками и интеллектуальной аналитикой.

---

## ✨ Возможности

### 📊 Dashboard (Главная панель)
- **Статистические карточки** с ключевыми показателями:
  - Общая выручка
  - Выручка за текущий месяц с процентом роста
  - Количество продаж
  - Средний чек
  - Количество клиентов и товаров
  - Ожидающие обработки заказы
  - Товары с низким остатком

- **Интерактивные графики** (Chart.js):
  - График динамики продаж за 12 месяцев (линейный, двойная ось Y)
  - Круговая диаграмма распределения по категориям
  - Горизонтальная диаграмма топ-10 продаваемых товаров

### 👥 Управление клиентами
- **Таблица клиентов** с сортировкой и поиском (DataTables)
- Отображение:
  - Контактная информация
  - Количество заказов
  - Общая сумма покупок
- **CRUD операции**:
  - ✅ Добавление клиента (модальное окно)
  - ✏️ Редактирование данных (inline editing)
  - ❌ Удаление клиента
- Валидация данных
- Уведомления об успешных операциях

### 📦 Управление товарами
- **Каталог товаров** с интерактивной таблицей
- Отображение:
  - Название, категория, цена
  - Количество на складе с цветовыми индикаторами
  - Количество проданных единиц
  - Статус наличия (В наличии / Заканчивается / Нет в наличии)
- **CRUD операции**:
  - ✅ Добавление товара с автодополнением категорий
  - ✏️ Редактирование (цена, остаток, описание)
  - ❌ Удаление товара
- Визуальные индикаторы низких остатков

### 💰 Продажи
- **История продаж** с детальной таблицей
- Отображение:
  - Клиент, дата, сумма
  - Статус (Завершена / Ожидает / Отменена)
  - Количество товаров в заказе
- Фильтрация по статусу
- Сортировка по дате (по умолчанию - новые первые)
- Просмотр деталей продажи

### 📈 Аналитика и рекомендации
- **Интеллектуальные рекомендации**:
  - ⚠️ Предупреждения о низких остатках
  - 💡 Советы по непродаваемым товарам
  - 📧 Рекомендации по работе с клиентами
  - 📊 Анализ роста/падения продаж

- **Анализ проблем с клиентами**:
  1. **Клиенты без покупок**
     - Зарегистрированы, но не совершили заказ
     - Количество дней с регистрации
     - Кнопка отправки промо-предложений

  2. **Неактивные клиенты**
     - Не покупали более 90 дней
     - Дата последней покупки
     - История предыдущих заказов
     - Функция отправки писем для возврата

  3. **Клиенты с отменами**
     - Статистика отмененных заказов
     - Процент отмен
     - Возможность связаться с клиентом

### ⚙️ Настройки
- **Персонализация Dashboard**:
  - Выбор отображаемых виджетов
  - Настройка графиков
- **Уведомления**:
  - О низких остатках товаров
  - О новых продажах
  - О неактивных клиентах
- **Информация о системе**:
  - Статус подключения к БД
  - Версия системы
  - Список возможностей

## 🛠️ Технологии

### Backend
- **Flask 3.0** - веб-фреймворк Python
- **pyodbc** - подключение к SQL Server
- **RESTful API** - все данные через API endpoints

### Frontend
- **Bootstrap 5.3** - современный UI framework
- **jQuery 3.7** - DOM манипуляции
- **Chart.js 4.4** - интерактивные графики
- **DataTables 1.13** - продвинутые таблицы
- **Font Awesome 6.4** - иконки
- **Custom CSS** - собственные стили и анимации

### Database
- **Microsoft SQL Server** - СУБД
- **4 таблицы**: Customers, Products, Sales, SaleDetails
- **3 связи**: Foreign Keys с каскадным удалением

## 📦 Установка и запуск

### Шаг 1: Установите зависимости

```powershell
# Установка Python пакетов
pip install Flask pyodbc
```

### Шаг 2: Убедитесь, что SQL Server запущен

- Сервер: `localhost`
- Логин: `sa`
- Пароль: `Aa123456`
- База данных будет создана автоматически при первом запуске

### Шаг 3: Запустите приложение

```powershell
python app.py
```

### Шаг 4: Откройте браузер

Приложение будет доступно по адресу:
```
http://localhost:5000
```

## 🌐 Маршруты приложения

### Страницы
- `GET /` - Dashboard (главная панель с графиками)
- `GET /customers` - Управление клиентами
- `GET /products` - Управление товарами
- `GET /sales` - История продаж
- `GET /analytics` - Аналитика и рекомендации
- `GET /settings` - Настройки системы

### API Endpoints

#### Dashboard
- `GET /api/dashboard/stats` - Статистика для главной панели
- `GET /api/dashboard/sales-chart` - Данные для графика продаж
- `GET /api/dashboard/top-products` - Топ-10 товаров
- `GET /api/dashboard/category-distribution` - Распределение по категориям

#### Customers
- `GET /api/customers` - Список всех клиентов
- `GET /api/customers/<id>` - Информация о клиенте
- `POST /api/customers` - Добавить клиента
- `PUT /api/customers/<id>` - Обновить клиента
- `DELETE /api/customers/<id>` - Удалить клиента

#### Products
- `GET /api/products` - Список всех товаров
- `POST /api/products` - Добавить товар
- `PUT /api/products/<id>` - Обновить товар
- `DELETE /api/products/<id>` - Удалить товар

#### Sales
- `GET /api/sales` - Список всех продаж

#### Analytics
- `GET /api/analytics/customer-problems` - Проблемы с клиентами
- `GET /api/analytics/recommendations` - Рекомендации для бизнеса
